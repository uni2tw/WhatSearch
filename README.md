# WhatSearch

一個給朋友用的個人 FTP 空間瀏覽/搜尋小工具：設定要分享的目錄後，朋友就能透過網頁搜尋、瀏覽、播放裡面的檔案，不用整包下載也不用翻 FTP 目錄。

## 功能

### 檔案瀏覽 / 搜尋
- 逐層瀏覽分享目錄，支援鍵盤方向鍵選取、Enter/→ 進入、← 回上層
- 檔名全文搜尋（Lucene.Net 索引），搜尋前會把簡體轉成繁體再比對
- 快速篩選 chip：只看音樂／只看影片／只看圖片
- 「最近上傳」聚合列表，跨資料夾依上傳時間排序
- 搜尋 0 筆結果時提供「回瀏覽模式」引導按鈕
- 搜尋輸入模式支援按 ESC 或點空白處退出

### 會員與登入
- 本地帳密登入/註冊（不依賴 Line 或其他第三方服務）
- 密碼以 PBKDF2 雜湊儲存；支援明碼過渡機制，可直接編輯 `users.json` 填入明碼密碼，該帳號下次登入時會自動轉存為雜湊
- 第一個註冊的帳號自動成為管理者並啟用；後續帳號需管理者到 `/admin` 頁面手動啟用
- 瀏覽、搜尋完全公開不需登入；只有要播放 MP3/影片時才需要登入
- 登入、登出都會導回原本瀏覽的頁面；未登入時點音樂/影片會先導去登入，登入成功後自動接續播放原本點擊的項目

### 媒體播放
- 音樂：頁面內建播放器，含進度條（可拖曳跳轉當前秒數）；單點單一首播完不會自動接下一首，要連續播放整個資料夾請用「播放全部」
- 音樂會顯示 ID3 tag 資訊（歌手/專輯），讀不到就不顯示
- 影片：頁面內疊層播放（非開新分頁）；播完會停下來，畫面上出現「播放下一部」讓你手動接續，不會自動跳下一部
- 圖片：Lightbox 疊層預覽，可用左右鍵或箭頭按鈕切換上一張/下一張
- 文字檔（`.md`/`.txt`）：疊層預覽，`.md` 用 Markdig 轉成 HTML 顯示、`.txt` 純文字顯示
- 正在播放/播放中的項目會標示選取樣式，方便在長列表中定位

### 上傳
- `/upload` 公開區、`/{36碼}/upload` 私人區（個人專屬，不用分享）、`/{6碼}/upload` 私人分享區（給朋友的短碼連結）
- 畫面上有公開/私人狀態 badge；私人分享區額外有「複製連結」按鈕
- 支援大檔分段續傳
- 上傳的圖片可直接預覽，不強制下載
- 檔案列表可直接刪除，上傳/刪除後局部更新列表，不用整頁重新整理
- 暫存/已上傳檔案超過時效會自動清除

### 其他
- `/about` 顯示 Markdown 說明文件

## 已知限制 / 之後想做的
- 音樂與影片同時播放時，播放影片只會自動暫停音樂，不會反向處理
- 手機觸控手勢（滑動快速動作）目前刻意不做，避免跟既有點擊/選取邏輯衝突
- 搜尋詞記憶/歷史，優先度較低，還沒做
